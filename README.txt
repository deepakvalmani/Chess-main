# Chess Game - Easy Setup Guide

## 🎮 Quick Start (Windows)

### Option 1: Run Directly
1. Double-click `Play Chess.bat`
2. The game will start automatically!

### Option 2: Run from Command Line
1. Open Command Prompt in this folder
2. Type: `Play Chess.bat` or double-click the batch file

---

## 📋 Requirements

- **Windows 10/11** (64-bit)
- No installation needed!
- No CMake or compiler required!

The game comes with everything bundled.

---

## 🎯 How to Play

1. **Click** on a piece to select it
2. **Click** on a highlighted square to move
3. **Right-click** to deselect a piece

### Game Controls
- **Left Click**: Select/Move piece
- **Right Click**: Cancel selection
- **Close Window**: Exit game

## 🛠️ Troubleshooting

### "DLL not found" error?
→ Make sure all files are in the same folder. Don't move individual files.

### Game doesn't start?
→ Right-click `Play Chess.bat` → Run as Administrator

### Black screen or crash?
→ Update your graphics drivers:
https://www.nvidia.com/download/index.aspx
https://www.amd.com/en/support
